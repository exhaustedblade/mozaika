# План

## 1. Ниша

По сводным обзорам (alternativeto.net, сравнение программ системной динамики в Википедии; поиск 21.10.2026) открытые инструменты закрывают один-два подхода из трёх, но не все в одной среде:

- **дискретно-событийный подход** — JaamSim;
- **агентный** — NetLogo, Repast, MASON, GAMA;
- **системная динамика** — LunaSim, Insight Maker, PySD;
- **непрерывные уравнения** — OpenModelica;
- **транспорт** — MATSim, SUMO.

Процессы, агентов и системную динамику на одних часах, вместе с ГИС, 3D и экспериментами, умеет только коммерческий AnyLogic.

**Свободное место:** открытая, современная, многоподходная среда, в которой модель строит ИИ.

**Цель масштаба и графики** (решение владельца 21.10.2026, П-18): реалистичные цифровые двойники для масштабных проектов, без жёсткого потолка по числу агентов.
- Сотни тысяч агентов на десктопе — норма.
- Миллион агентов с простой логикой — цель.
- Графика — сильная сторона продукта: WebGPU, физически корректные материалы (PBR), тени, освещение, 3D-карты.

Главная форма продукта — настольное приложение для Windows и macOS; браузер по ссылке остаётся для показа моделей заказчику (П-19).

## 2. Принцип: пишем 4 вещи, остальное берём

### Пишем сами

1. **Единое ядро времени.** Очередь событий, процессы-корутины, агенты с диаграммами состояний, системная динамика с шагом dt — всё на одних часах. Детерминированность (seed), одновременные события по правилам, пересечение порогов в непрерывных переменных.
2. **Библиотека блоков** по методу «чистой комнаты» ([LEGAL.md](LEGAL.md)):
   - процессные блоки: Source, Sink, Queue, Delay, Service, Seize, Release, ResourcePool, SelectOutput, Hold, Match, Batch/Unbatch, Split/Combine, Conveyor (позже);
   - тесты правильности против теории очередей (M/M/1, M/M/c, Литтл) и опубликованных эталонных моделей.
3. **Редактор:** блок-схемы, свойства, сцена 2D/3D, графики, панели управления, код внутри модели.
4. **ИИ-слой и проверка модели:**
   - MCP-инструменты «построй / измени / запусти / покажи / исследуй / проверь»;
   - встроенная самопроверка (законы модели, балансы, монотонность);
   - независимый пересчёт и анализ устойчивости — подход уже опробован на практическом проекте цифрового двойника.

## 3. Чем современнее AnyLogic

- **ИИ с первого дня:** модель по описанию, рисунку, данным; ИИ проверяет её сам.
- **Модель — текстовые файлы:** git, сравнение версий, ревью, совместная работа. У AnyLogic — один большой XML.
- **Масштаб без жёсткого потолка:** сотни тысяч агентов на десктопе — норма, миллион с простой логикой — цель (П-18).
- **Графика как сильная сторона:** WebGPU, физически корректные материалы, тени, освещение, 3D-карты.
- **Настольное приложение и ссылка:** главная форма — приложение для Windows и macOS (П-19). Ту же модель можно открыть в браузере по ссылке, чтобы показать заказчику без установки, и в окне VS Code.
- **Встроенная проверка:** самопроверка, балансы, независимый пересчёт, устойчивость индексов.
- **Связь с Python и Jupyter** для аналитиков.
- **Открытые плагины:** любой может добавить свою библиотеку блоков.

## 4. Фазы

**Фаза 0 — проба (1–2 недели).**
- Ядро, Source → Queue/Service → Sink, агент с состояниями, один запас системной динамики на общих часах.
- 3D-окно, управление через MCP из Claude Code.
- Итог: окончательный выбор стека (DECISIONS.md, Р-1).

**Фаза 1 — версия 0.1, открытая (3–4 месяца).**
- Ядро и ~12 процессных блоков, агенты, системная динамика.
- Редактор (блок-схема, свойства), 2D/3D, графики, панели управления.
- Эксперименты: варьирование параметров, Монте-Карло.
- Импорт CSV/Excel, ИИ через MCP, самопроверка.
- **Критерий готовности:** пересобраны 2–3 наших демо-модели (цифровой двойник и процессные модели) не хуже, чем в AnyLogic; блоки проходят тесты теории очередей.

**Фаза 2 (3–4 месяца).**
- ГИС с маршрутами; оптимизация и калибровка.
- Движение в пространстве, сети путей, простые пешеходы.
- Публикация модели по ссылке.
- Скорость: ядро — отдельный процесс на десктопе (в браузере — Web Worker), параллельные прогоны по ядрам процессора; ядро событий — TypeScript с данными в массивах, пакетные расчёты (движение, пространственный индекс) — на Rust или WebAssembly (П-27).
- Галерея шаблонов.

**Фаза 3 (от полугода).**
- Трафик через SUMO, пешеходы через JuPedSim.
- Железная дорога, склады и конвейеры.
- Совместная работа, облачные прогоны, «кинорежим» (экспорт сцены в Godot для презентаций).

**Итого:** примерно год до конкурента в основных сценариях. Полного паритета со всеми специальными библиотеками AnyLogic не нужно.

## 5. Риски

| Риск | Как закрываем |
|---|---|
| Расползание объёма | строгие фазы; правило «сначала пересобираем реальную модель, потом новые блоки» |
| Скорость на больших моделях | ядро — отдельный процесс на десктопе; данные ядра и снимки больших популяций — плотными числовыми массивами; движение — отрезками; отрисовка через видеокарту (инстансинг, deck.gl); пакетные расчёты — на Rust или WebAssembly (П-27); замеры в Ф0-4, Ф0-4б и Ф0-6 |
| Правильность блоков | тесты против точных формул теории очередей и эталонных моделей; встроенная самопроверка |
| Многоподходность (стыки времени) | одно ядро и одни часы с первого дня; тесты стыков (порог системной динамики посреди шага, одновременные события) |
| Юридическая чистота | правила «чистой комнаты» ([LEGAL.md](LEGAL.md)); юрист перед коммерческим запуском |
| Ограничения ИИ-сессий и потеря контекста | всё важное — в документах репозитория (план, решения, журнал), тесты как страховка |
| Деньги при открытом коде | open core (раздел 6) |
| Подпись приложений | без подписи macOS не даёт просто запустить скачанное приложение, а Windows предупреждает пользователя. Подпись нужна, только когда появятся внешние пользователи; условия и цены — ниже |

### Подпись приложений

Условия и цены проверены 21.10.2026 по официальным страницам.

**macOS**
- Нужен [Apple Developer Program](https://developer.apple.com/programs/): 99 $ в год.
- Приложение подписывается сертификатом [Developer ID](https://developer.apple.com/developer-id/) и проходит нотаризацию — проверку в сервисе Apple (`notarytool`). Иначе Gatekeeper не даёт просто запустить скачанное приложение.
- Сертификат Developer ID выпускает только владелец аккаунта программы.
- Бесплатно программа доступна только [некоммерческим, учебным и государственным организациям](https://developer.apple.com/support/membership-fee-waiver/), не частным лицам.
- Оплата зависит от страны. По сообщениям разработчиков на форумах Apple, из России оплата и продление сейчас проходят нестабильно — проверить заранее.

**Windows**
- Нужен сертификат подписи кода.
- Для открытых проектов есть бесплатная подпись от [SignPath Foundation](https://signpath.org/). [Условия](https://signpath.org/terms):
  - лицензия, одобренная OSI, у всех компонентов, без закрытых частей и без коммерческого двойного лицензирования;
  - сборка из исходников проверяемым способом (CI);
  - ручное подтверждение каждого релиза;
  - многофакторная аутентификация у всей команды;
  - раздел «Code signing policy» на сайте.
- Значит, сначала нужно решить Р-3 (лицензия), а платные части open core не должны входить в подписываемую сборку.
- Платная альтернатива — [Microsoft Artifact Signing](https://azure.microsoft.com/pricing/details/artifact-signing/): от 9,99 $ в месяц. Но [доступна](https://learn.microsoft.com/azure/artifact-signing/quickstart) она только организациям из ряда стран и частным лицам из США и Канады.
- Даже подписанное приложение может какое-то время получать предупреждение SmartScreen, пока не наберёт репутацию.

- **бесплатно и открыто:** ядро, блоки, редактор;
- **платно:**

  - ИИ-кредиты (построение и проверка моделей);
  - отраслевые библиотеки и шаблоны;
  - цифровые двойники под ключ;
  - поддержка и обучение.
