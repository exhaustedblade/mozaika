# Задачи Фазы 0 (проба, 1–2 недели)

Готовые карточки для GitHub Issues: одна карточка — одна сессия. Стек — рекомендованный веб/TypeScript (Р-1). По итогам пробы решение Р-1 фиксируется окончательно.

## Ф0-1. Каркас репозитория и автоматические проверки

**Цель:**
- TypeScript strict, Vitest, линтер, структура `packages/kernel`, `packages/blocks`, `packages/viewer`, `packages/mcp`;
- GitHub Actions: типы, тесты, сборка, превью на GitHub Pages.

**Готово, когда:** пустой проект собирается в CI, превью открывается по ссылке.

## Ф0-2. Ядро времени

**Цель:**
- очередь событий (время, приоритет, порядковый номер);
- процессы на генераторах (`yield timeout`, ожидание сигнала);
- генератор случайных чисел с seed;
- прогон без отрисовки, с выдачей снимков состояния.

**Готово, когда:** тесты на порядок одновременных событий и повторяемость по seed зелёные; 1 млн событий проходит за разумное время (замер в CI).

## Ф0-3. Первые блоки и ресурсы

**Цель:** Source, Queue, Service (с ResourcePool), Delay, Sink, статистика (длина очереди, загрузка, время в системе).

**Готово, когда:** M/M/1 и M/M/c совпадают с формулами теории очередей в пределах доверительного интервала; закон Литтла выполняется.

## Ф0-4. Агент с диаграммой состояний

**Цель:** тип агента с полями и состояниями, переходы по таймауту, условию и сообщению; агент может пройти через процессные блоки как сущность.

**Готово, когда:** тест «агент меняет состояние в ожидаемые моменты» и тест «агент как сущность в очереди» зелёные.

## Ф0-5. Системная динамика на тех же часах

**Цель:** запасы, потоки, переменные, интегрирование с шагом dt; событие при пересечении порога посреди шага; агенты читают и меняют переменные.

**Готово, когда:** аналитическая проверка (экспоненциальный рост и распад) в пределах погрешности; порог ловится в правильный момент.

## Ф0-6. Просмотр

**Цель:** веб-просмотр: 3D-сцена (Babylon.js или three.js) с движущимися агентами и очередью, графики (ECharts), простая панель параметров. Ядро в Web Worker.

**Готово, когда:** демо «пункт обслуживания» открывается по ссылке, выглядит прилично, ядро не тормозит отрисовку.

## Ф0-7. ИИ-управление через MCP

**Цель:** MCP-сервер с инструментами `status`, `change`, `run`, `watch` (по словарю Architect).

**Готово, когда:** Claude Code по словесному описанию собирает и меняет демо-модель, запускает её и показывает кадр.

## Ф0-8. Итоги пробы

**Цель:** отчёт владельцу: что получилось, скорость, сложные места, рекомендация по Р-1 и Р-7, оценка Фазы 1.

**Готово, когда:** решение Р-1 записано в `docs/DECISIONS.md`.
