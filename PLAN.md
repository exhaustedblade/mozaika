# План

## 1. Ниша

По сводным обзорам (alternativeto.net, сравнение программ системной динамики в Википедии; поиск 21.10.2026) открытые инструменты закрывают один-два подхода из трёх, но не все в одной среде:

- **дискретно-событийный подход** — JaamSim;
- **агентный** — NetLogo, Repast, MASON, GAMA;
- **системная динамика** — LunaSim, Insight Maker, PySD;
- **непрерывные уравнения** — OpenModelica;
- **транспорт** — MATSim, SUMO.

Процессы, агентов и системную динамику на одних часах, вместе с ГИС, 3D и экспериментами, умеет только коммерческий AnyLogic.

**Свободное место:** открытая, современная, многоподходная среда, в которой модель строит ИИ.

## 2. Принцип: пишем 4 вещи, остальное берём

### Пишем сами

1. **Единое ядро времени.** Очередь событий, процессы-корутины, агенты с диаграммами состояний, системная динамика с шагом dt — всё на одних часах. Детерминированность (seed), одновременные события по правилам, пересечение порогов в непрерывных переменных.
2. **Библиотека блоков** по методу «чистой комнаты» ([LEGAL.md](LEGAL.md)):
   - процессные блоки: Source, Sink, Queue, Delay, Service, Seize, Release, ResourcePool, SelectOutput, Hold, Match, Batch/Unbatch, Split/Combine, Conveyor (позже);
   - тесты правильности против теории очередей (M/M/1, M/M/c, Литтл) и опубликованных эталонных моделей.
3. **Редактор:** блок-схемы, свойства, сцена 2D/3D, графики, панели управления, код внутри модели.
4. **ИИ-слой и проверка модели:**
   - MCP-инструменты «построй / измени / запусти / покажи / исследуй / проверь»;
   - встроенная самопроверка (законы модели, балансы, монотонность);
   - независимый пересчёт и анализ устойчивости — как в модели для ЦЭМИ.

## 3. Чем современнее AnyLogic

- **ИИ с первого дня:** модель по описанию, рисунку, данным; ИИ проверяет её сам.
- **Модель — текстовые файлы:** git, сравнение версий, ревью, совместная работа. У AnyLogic — один большой XML.
- **Ссылка вместо установки:** модель открывается в браузере у заказчика. Тот же проект работает в окне VS Code и в настольном приложении.
- **Красивое 3D и современные карты** на WebGPU.
- **Встроенная проверка:** самопроверка, балансы, независимый пересчёт, устойчивость индексов.
- **Связь с Python и Jupyter** для аналитиков.
- **Открытые плагины:** любой может добавить свою библиотеку блоков.

## 4. Фазы

**Фаза 0 — проба (1–2 недели).**
- Ядро, Source → Queue/Service → Sink, агент с состояниями, один запас системной динамики на общих часах.
- 3D-окно, управление через MCP из Claude Code.
- Итог: окончательный выбор стека (DECISIONS.md, Р-1).

**Фаза 1 — версия 0.1, открытая (3–4 месяца).**
- Ядро и ~12 процессных блоков, агенты, системная динамика.
- Редактор (блок-схема, свойства), 2D/3D, графики, панели управления.
- Эксперименты: варьирование параметров, Монте-Карло.
- Импорт CSV/Excel, ИИ через MCP, самопроверка.
- **Критерий готовности:** пересобраны 2–3 наших демо (двойник для ЦЭМИ, NYC EMS, ещё одна процессная модель) не хуже, чем в AnyLogic; блоки проходят тесты теории очередей.

**Фаза 2 (3–4 месяца).**
- ГИС с маршрутами; оптимизация и калибровка.
- Движение в пространстве, сети путей, простые пешеходы.
- Публикация модели по ссылке.
- Скорость: ядро в отдельном потоке, параллельные прогоны, горячие места в WebAssembly.
- Галерея шаблонов.

**Фаза 3 (от полугода).**
- Трафик через SUMO, пешеходы через JuPedSim.
- Железная дорога, склады и конвейеры.
- Совместная работа, облачные прогоны, «кинорежим» (экспорт сцены в Godot для презентаций).

**Итого:** примерно год до конкурента в основных сценариях. Полного паритета со всеми специальными библиотеками AnyLogic не нужно.

## 5. Риски

| Риск | Как закрываем |
|---|---|
| Расползание объёма | строгие фазы; правило «сначала пересобираем реальную модель, потом новые блоки» |
| Скорость на больших моделях | ядро в отдельном потоке, WebAssembly для горячих мест, отрисовка через видеокарту (инстансинг, deck.gl) |
| Правильность блоков | тесты против точных формул теории очередей и эталонных моделей; встроенная самопроверка |
| Многоподходность (стыки времени) | одно ядро и одни часы с первого дня; тесты стыков (порог системной динамики посреди шага, одновременные события) |
| Юридическая чистота | правила «чистой комнаты» ([LEGAL.md](LEGAL.md)); юрист перед коммерческим запуском |
| Ограничения ИИ-сессий и потеря контекста | всё важное — в документах репозитория (план, решения, журнал), тесты как страховка |
| Деньги при открытом коде | open core (раздел 6) |

## 6. Деньги

Open core:
- **бесплатно и открыто:** ядро, блоки, редактор;
- **платно:**
  - облачные прогоны и хостинг моделей по ссылке;
  - ИИ-кредиты (построение и проверка моделей);
  - отраслевые библиотеки и шаблоны;
  - цифровые двойники под ключ (как модель для ЦЭМИ);
  - поддержка и обучение.
